# Отчёт о проверке — 2026-10-30

Приведённые тестовые сценарии выполнялись в отдельном локальном проекте разработки SmartBalancer; их исходники в этот репозиторий не загружены. Публикуемый `smartbalancer.js` содержит исходный JavaScript плагина.

Среда: Linux, Node.js v24.19.0, npm 11.9.0, Chromium 154.0.8037.57. Собрана настоящая Lampa 3.4.4, commit `7cf18c6e855301975ac416e077006f9bb84e69e0`, в отдельном временном каталоге. Android TV, Xiaomi Stick и Vimu недоступны.

`npm ci --ignore-scripts && npm run build && npm run lint && npm test`: успешно, **35/35** тестов в `tests/core.test.js` и `tests/ui.test.js`. `lint` — только `node --check`. Два дополнительных браузерных сценария требуют локально установленного Playwright и Chromium, работающей Lampa на порту 3000 и `python3 -m http.server 8765 --bind 127.0.0.1` в корне проекта:

- `node tests/lampa-browser.cjs`: реальный загрузчик Lampa, видимая кнопка, Enter, меню, Back, 20 переоткрытий, возврат к сохранённой карточке, выбор серии и история; переключение карточки во время задержанного поиска не запускает старую ссылку; отдельные unit-тесты проверяют блокировку устаревшего меню и позднего события карточки. Ответы каталога/видео перехвачены, `Player.play` подменён; это не проверка реального воспроизведения и физического пульта.
- `LAMPA_REAL_TMDB=1 node tests/lampa-live.cjs`: реальная карточка TMDB Big Buck Bunny 10378, встроенный каталог, реальный HLS Mux, настоящий встроенный плеер Lampa в Chromium; видео начало играть (`currentTime > 0.2`). Весь фильм, Android и Vimu не проверены. При отсутствии опции `LAMPA_REAL_TMDB=1` метаданные карточки подставные.

Для воспроизведения этих сценариев клонируйте Lampa на указанный commit, выполните в её папке `npm install && npm run start`; установите Playwright вне production-проекта и используйте совместимый Chromium. Дополнительные браузерные зависимости не входят в `dist` и не фиксируются этим lock-файлом. Доступ в сеть нужен для TMDB и Mux.

Сетевые проверки: Mux HLS HEAD 200 с CORS `*`. Sintel MP4 Internet Archive: HEAD 200, Range 0–1023 — 206 и 1024 байта; обычный HTML video в Chromium начал воспроизводить около 0,46 секунды. Через встроенный плеер Lampa воспроизведение того же MP4 не удалось; в финальной цепочке не было CORS-заголовка, у video Lampa установлен `crossorigin=anonymous`. HEAD официального Blender MKV — 200; ранее запрос Range вернул 200 и был остановлен ограничением размера.

## Ручной чек-лист на Xiaomi TV Stick + Vimu — не выполнен

1. Разместить JS на своём HTTPS-хостинге, установить через «Расширения», перезапустить. Проверить штатные кнопки и hdrezka.js, 20 открытий карточек, стрелки/OK/Back и отсутствие дублей.
2. Выбрать в Lampa внешний Android-плеер и Vimu; открыть TMDB Big Buck Bunny 10378, нажать кнопку SmartBalancer, проверить изображение и звук в Vimu и возвращение в Lampa.
3. Открыть Sintel 45745, попробовать `unknown` вручную, записать фактический результат Vimu. Сравнить с ограничением встроенного плеера.
4. Подключить разрешённые пользовательские HTTPS-каталоги с CORS; проверить фильм и серии, specials, различия нумерации и озвучки, тайм-аут, отмену и смену карточки во время поиска. Проверить два независимых источника одного фильма.
5. Зафиксировать версии Lampa/Android/Vimu, время до результата, отзывчивость пульта и стабильность при 10–20 циклах; проверить отключение плагина и перезапуск. Тесты и численные бюджеты Chromium не подтверждают производительность Stick.
