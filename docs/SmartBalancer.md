# Lampa SmartBalancer 0.2.1

Экспериментальный плагин добавляет в карточку Lampa кнопку для выбора прямого потока из разрешённых источников. Встроенный каталог содержит только два открытых фильма Blender; для других фильмов и сериалов нужен пользовательский HTTPS JSON-каталог. Автоматического подключения к уже установленным онлайн-плагинам нет.

## Установка

Добавьте в расширениях Lampa адрес:

```text
https://simsomnat.github.io/lampa-plugins/smartbalancer.js
```

Перезапустите Lampa. Для проверки откройте в TMDB карточку **Big Buck Bunny (2008)**, ID 10378, и нажмите «Смотреть · SB». Для остальных фильмов задайте URL каталога в настройках SmartBalancer. Удержание кнопки или меню «…» карточки открывает дополнительные источники и диагностику. Отключение: удалите или выключите плагин в расширениях и полностью перезапустите Lampa.

Выбор Android-плеера/Vimu выполняется в Lampa и системном диалоге. Работа на Xiaomi TV Stick, с Vimu и с реальными сериалами не проверена. Встроенный Sintel с Internet Archive может быть недоступен во встроенном плеере Lampa из-за CORS; статус `unknown` не доказывает недоступность для внешнего плеера. Восстановление позиции и автоматическое переключение при ошибке Vimu не реализованы.

## Пользовательский каталог

Формат — JSON `{ "version": 1, "items": [...] }`, сервер должен разрешать CORS для origin Lampa. [Пример для Sintel](SmartBalancer-sintel-catalog.json).

Для фильма запись содержит `type: "movie"`, `ids: {"tmdb": 123}` либо `ids: {"imdb": "tt..."}`, `year`, HTTPS `url` и необязательные `format` (`hls`, `dash`, `mp4`, `mkv`), `resolution`, `language`, `voiceover`, `expiresAt` в ISO-8601. Для серии задайте `type: "tv"`, целочисленные `season`, `episode` и, **только если нумерация действительно совпадает с TMDB**, `episodeOrder: "tmdb"`. Без этого подтверждения серия доступна только для ручного выбора. Плагин не может проверить, что содержимое файла соответствует метаданным каталога.

Работают до двух пользовательских каталогов одновременно. Поддерживаются только прямые HTTPS-ссылки без логина и пароля; заголовки, cookies, DRM, авторизация и извлечение URL из iframe не поддерживаются. Не размещайте секреты в публичном каталоге: Lampa сама может записывать URL плеера в журнал. Сеть, CORS или тайм-аут могут давать статус `unknown`; это не означает, что ссылка сломана.
